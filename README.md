# 🧮 Loan Calculator

A simple, lightweight, and responsive web-based **Loan Calculator** built using HTML5, CSS3, and Vanilla JavaScript. It helps users quickly calculate their monthly loan installments (EMI), total interest, and total payment amounts based on the principal loan amount, interest rate, and loan tenure.

---

## ✨ Features

* **Instant Calculations:** Computes monthly payments, total interest, and total repayment amounts on the fly.
* **Responsive Design:** Looks great and functions smoothly across both desktop and mobile devices.
* **Clean UI:** Styled with a modern glassmorphism/minimalist touch and user-friendly focus states.
* **Vanilla JavaScript:** Built entirely without heavy frameworks or libraries for optimal performance.

## 📐 Mathematical Formulas Used

1. **Monthly Payment ($M$):**
   $$M = P \frac{r(1 + r)^n}{(1 + r)^n - 1}$$
   *Where $P$ is Principal, $r$ is Monthly Interest Rate, and $n$ is Total Months.*

2. **Total Payment:**
   $$\text{Total Payment} = \text{Monthly Payment} \times \text{Total Months}$$

3. **Total Interest:**
   $$\text{Total Interest} = \text{Total Payment} - \text{Principal Amount}$$

## 💻 Getting Started

To run this project locally on your machine, follow these simple steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/dev-deepak-prajapati/loan-calculator.git
   ```

2. **Navigate into the project directory:**
   ```bash
   cd loan-calculator
   ```

3. **Launch the application:**
   Simply double-click the `index.html` file to open it directly in any modern web browser, or use a local server tool like VS Code's *Live Server* extension.
